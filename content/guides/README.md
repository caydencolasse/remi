# Guides

Each guide is one Markdown file. Remii answers from these with no connection.

## Format

```markdown
---
id: power-outage
title: Power outage
status: draft            # draft | reviewed
reviewed_by: null        # name and credential once reviewed
reviewed_on: null        # YYYY-MM-DD
life_safety: false       # true = steps are shown word for word, never reworded
on_watch: true           # also stored on the Apple Watch
sources: []              # where the content came from, with licence
---

One-line summary.

## Steps

1. First step.
2. Second step.

## Notes

Anything that is not a step.
```

## Rules

- Every guide here is a **draft** written to test the app. None has been
  reviewed by a qualified person. A draft must not ship to users.
- Keep each step to one action in one sentence.
- Record the source and its licence. US government material (FEMA, Ready.gov,
  CDC) is free to reuse. Most other published material needs a licence.
